# Dopamine Pricing Web V8.0.2 — 正式部署版

## 版本说明

- 新建项目的首个套餐、新建套餐的默认折扣均调整为 **6折、6.5折、7折**。
- 仅更新新建时的默认值；已有项目、套餐及用户自定义折扣完全保留。
- 不修改历史数据、成本与折扣计算逻辑。


V8.0.2 将已验收的高保真 UI 应用到 V7 的正式业务数据结构，保留项目、套餐、产品成本、组合、单品价格、折扣、费用、利润计算及 Excel/WPS 批量复制粘贴。

### 最终 UI 调整

- 桌面宽屏保留左侧业务导航，取消页面右侧重复切换按钮；侧栏隐藏的小屏才在顶部提供紧凑切换入口。
- 套餐四项摘要（当前套餐、商品数量、原价总额、原价套餐利润）合并进套餐操作栏 **同一张白色卡片**。
- 汇总表左表头“指标”改成“折扣方案”；商品总数量显示 `20P`（非整数数量按实际保留小数，如 `20.5P`）。
- 采用 Zendenta 结构化工作台导航和 Bringova 轻量表格设计，保留紧凑业务录入。
- 产品管理支持产品/组合筛选、搜索和组合展开。

### V7 数据兼容

- 沿用正式的 `localStorage` key：`dopamine-pricing-web-v1`，与 V7 **相同**。
- 继续使用 V7 数据模型版本 `4`，不改变计算算法和基础数据结构。
- 全新用户首次打开为空白项目，不加入原型演示数据。
- 保留 V1–V6 数据迁移、V7 项目数据、JSON 备份/恢复。
- 先在 V7 线上点击「导出备份」保存 JSON，再部署 V8。重要数据建议升级后重新导出一次备份。

### 工作方式

- Cloudflare Pages 仅部署静态代码；所有项目和成本数据仍存于当前浏览器 localStorage。
- 没有用户账号、云同步或服务端数据库；清理站点数据、换浏览器或域名可能导致本地数据无法访问，使用 JSON 备份迁移。
- **请保持现有 Pages 域名**，更换域名会变更浏览器存储 origin，即使 key 相同也不能自动读取原有数据。

### 部署

将压缩包中的文件覆盖现有独立网页版仓库（不是 Dopamine Desktop 仓库），推送 GitHub `main`：

- Framework preset：None
- Build command：`npm run build`
- Output directory：`dist`
- Production branch：`main`

无需新增环境变量、数据库或服务，运行时不使用 CDN。

### 本地检查

```bash
node --check app.js
npm run build
```

建议验收：旧项目载入；组合成本改变联动套餐成本；折扣和附加费用同步；批量单列粘贴；项目切换；保存与刷新；1366×768 小屏操作。


## V8.0.2 修复

- 折扣价列改为「折扣价小计」：单品标价 × 数量 × 折扣系数；折扣利润小计与其使用相同数量口径。
- 金额内部计算采用 BigInt 固定 12 位小数精度；金额仅在显示时四舍五入至 2 位，单品成本显示 4 位。每次乘法在第 12 位进行一次舍入，不使用已经显示为 2 位的金额继续计算。
- 不改变 localStorage 键、业务数据结构或现有项目内容。
