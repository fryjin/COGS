# Dopamine Pricing Web

> V7：出厂价格设置改为「产品信息设置」；单品标价集中维护、单品利润自动计算，套餐只引用产品价格；支持 Excel/WPS 单列批量粘贴及从指定行直接粘贴。

> V6：新增多项目管理（每个项目独立出厂价格与套餐）；新增 Excel/WPS 多行批量复制 / 粘贴。

> V5：套餐售价三大计算区高度扩大约 2 倍；出厂价格设置表格列宽压缩，优先保证操作列在小屏首屏可见。

> V4：小屏表格紧凑布局；产品/费用区滚动到底后继续滚动整个页面，减少双滚动区操作负担。

> V3：出厂价格设置、小屏高度优化、顶部操作区常驻、数字输入改为 Enter/失焦确认。

一个独立、纯前端的套餐售价 / 成本 / 折扣 / 利润计算工具。

## 当前功能

- 产品信息设置：普通产品、组合、规格/备注、单个成本、**单品标价、自动计算单品利润**、启用/停用
- 组合成本：维护成份及成份数量，组合单个成本自动按 `Σ(成份成本 × 数量)` 计算，并可继续用于套餐售价计算
- 多套餐：新建、复制、重命名、删除、切换
- 套餐产品：选择项目产品并填写数量，单品标价自动从「产品信息设置」读取，不再在多个套餐中分别维护
- 自动计算：单品成本、成本小计、单品利润（产品信息页）、标价小计、商品利润小计、折扣与利润
- 动态折扣方案：可新增 / 删除 / 修改多个折扣
- 附加成本：固定金额或售价百分比
- 合计结果：销售总额、商品成本、固定附加成本、售价比例费用、完整成本、套餐利润、毛利率、成本率
- 本地保存：使用浏览器 localStorage；自动兼容 V1–V6 旧数据，首次保存升级到 V7 数据结构（version 4）
- JSON 备份与恢复：用于换浏览器/换设备时手动迁移数据

## 数据说明

这是一个纯静态网页版本，不连接服务器。

Cloudflare Pages 只托管网页代码，业务数据默认保存在当前浏览器的 `localStorage` 中。因此：

- 同一浏览器再次打开会保留已保存数据；
- 换电脑、换浏览器、清理浏览器数据后不会自动同步；
- 建议定期使用“导出备份”保存 JSON；
- 后续如需多设备联网同步，可以再增加 Cloudflare Workers + D1。

建议单独创建仓库，例如：

```text
dopamine-pricing-web
```

将本目录全部文件提交到 `main`。

## Cloudflare Pages 部署

1. 打开 Cloudflare Dashboard → Workers & Pages。
2. Create application → Pages → Import an existing Git repository。
3. 选择对应 GitHub 仓库。
4. Production branch：`main`
5. Framework preset：None
6. Build command：`npm run build`
7. Build output directory：`dist`
8. 保存并部署。

之后每次 push 到 `main`，Cloudflare Pages 会自动重新构建和发布。

## 技术特点

- 无前端框架
- 无运行时 npm 依赖
- 无数据库
- 无服务器
- 无第三方 CDN
- 计算使用固定精度 BigInt，避免常见 JS 浮点金额误差


## V6：多个项目与批量复制粘贴

- 顶部项目下拉列表用于切换多个独立项目，每个项目拥有自己的出厂价格库、组合、套餐和折扣。
- 支持新建、复制、重命名、删除项目；项目之间不共享产品 ID 或组合引用。
- 当前项目中可以切换多个套餐。旧 V1/V2 浏览器数据会自动作为「项目1」读取，首次保存后升级到 V3 数据结构。
- 产品信息设置/套餐售价计算新增「批量复制 / 粘贴」。从 Excel/WPS 中复制单元格，选择数据类型后粘贴到窗口，一次处理多行。也可以在商品输入框中直接粘贴带制表符或换行的内容来打开批量窗口。
- 出厂价格简表列：`产品名称 → 单个成本 → 规格/备注 → 状态`；兼容完整六列表 `产品品类 → 成份 → 成份数量 → 规格/备注 → 单个成本 → 状态`，以及组合续行。
- 套餐产品列：`产品品类 → 产品数量`，以当前项目出厂价格库中的名称/规格查找，已有行覆盖数量和标价，新产品添加。
- 附加费用列：`费用名称 → 计算方式（固定金额/售价百分比） → 数值`。
- **粘贴具有原子性**：任意一行不合法、产品未找到、组合循环或规格名称歧义时，不会应用任何行，错误显示在窗口内。
- 备份现在包含全部项目，仍仅在浏览器本机保存，没有多设备同步。


## V7：产品统一定价与单列批量粘贴

- 进入「产品信息设置」，在普通产品或组合产品旁直接填写**单品标价**。同一项目中的所有套餐自动引用该售价，**单品利润 = 单品标价 − 单个成本**。组合产品的单个成本继续按成份自动汇总，标价由用户输入。
- 套餐售价计算区不再编辑或重复显示「单品标价、单品利润」两列，保留成本小计、标价小计、商品利润小计及各折扣结果。修改产品信息里的标价会同步刷新所有引用该商品的套餐。
- 「批量复制 / 粘贴」窗口可选择**整表多列**或**单列批量**，单列模式先选目标列，粘贴一列多行并点击应用。单列从列表**第 1 行**往下对应填入。
- **在表格中直接粘贴单列**：选择单个成本、单品标价、产品名称、规格、数量、费用数值等输入框，直接 Ctrl+V 从当前行开始逐行填入。单列可以包含多行，任意行错误会整批拒绝。部分字段在超出已存在的行时会新增产品；数量超出已有套餐产品行则拒绝，防止错误匹配。
- 已有多列批量粘贴仍可使用，新的产品信息完整表为：`产品品类 / 成份 / 成份数量 / 规格/备注 / 单个成本 / 单品标价 / 状态`；原 V6 六列表与简表也支持。
- **旧数据兼容**：V6 单品标价存于不同套餐，V7 自动迁移到项目产品信息。若同一产品在不同套餐原先使用了**不同标价**，系统会保留两条可区分的价格条目（第二条规格标识「旧售价 X」），原套餐引用自动调整，从而保留升级前的各套餐售价与利润。请按需要整理合并。
- 升级后顶部如显示「旧数据已兼容升级，请保存」，请先**导出备份**，核对后点击保存；切勿清空浏览器站点数据。
- 当前仍为**纯本地浏览器数据**，Cloudflare Pages 仅托管静态资源。无服务端实时同步。
